# RetCon 2026 — ZX Spectrum 48K Demo

A small Z80 assembly demo for the 48K ZX Spectrum, built for RetCon 2026. Two
lines of wire-frame letters — `WELCOMETO` / `RETCON2026` — animate through three
phases over a twinkling starfield, washed with scrolling rainbow colour.

## The three phases

1. **Scroll** — the two lines of letters ease in from off-screen to their rest
   positions.
2. **Spin** — all 19 letters rotate 360° about their own centres (signed 8×8
   multiply + 2D rotation, drawn with Bresenham lines).
3. **Orbit** — each letter spirals out from and back to its centre with a
   per-letter phase stagger.

…then it loops.

## Effects / techniques

- **Flicker-free rendering.** The Spectrum has a single screen buffer and no
  page-flip, so every phase renders into a **shadow buffer** at `0xC000`
  (= screen address `| 0x8000`) and then copies only the affected rows to the
  live screen. The ULA never sees the clear-then-redraw gap, so there's no
  blinking — at worst a single clean tear line.
- **Fast spin.** Incremental-addressing Bresenham (`draw_line_fast`) tracks the
  screen pointer and bit mask as each line walks, instead of recomputing the
  address per pixel. Band clears/copies are unrolled.
- **Fast orbit.** The sprite blitter uses incremental next-line addressing, and
  the clear/copy band is sized dynamically to the current orbit radius.
- **Rainbow colour wash.** An attribute-plane effect (`0x5800`): a per-row colour
  pattern is rotated each frame so the colours flow through the letter pixels.
  Independent of the pixel pipeline, so it costs almost nothing.
- **Starfield.** A scattered field of stars drawn behind everything,
  re-composited into the shadow band each frame so the letters don't erase them,
  with a few stars twinkling on/off. They pick up the rainbow colours for free.

Two pacing dials live at the top of `src/main.asm`: `SPIN_STEP` (spin speed) and
`ORB_STEP` (orbit speed), both 8.8 fixed-point steps where `256` = 1.0×.

## Build

Requires [Pasmo](https://pasmo.speccy.org/) (a copy of `pasmo.exe` is included
under `tools/`).

```
build.bat
```

This assembles `src/main.asm` to `build/demo.tap` (a `.tap` with a BASIC loader).

## Run

Load `build/demo.tap` in any 48K Spectrum emulator (e.g. Spectaculator,
EightyOne, Fuse) — it loads and runs directly.

## Source layout

| File | Contents |
|------|----------|
| `src/main.asm` | Entry point, phase state machine, pacing constants |
| `src/render.asm` | Pixel/line plotting, sprite blit, shadow buffer, rotation, rainbow |
| `src/stars.asm` | Starfield (scatter, stamp, twinkle) |
| `src/font.asm` | Letter shapes and rest positions (generated) |
| `src/tables.asm` | sin table, screen row addresses, animation curves (generated) |
| `tools/gen.py` | Regenerates `font.asm` / `tables.asm` |

`font.asm` and `tables.asm` are generated by `tools/gen.py`; edit the generator
rather than the tables by hand.
